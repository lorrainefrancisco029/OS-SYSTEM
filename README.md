# Barangay OS System

React + Vite + Bootstrap-style dashboard for the Barangay OS project.

## Run the project

1. Open a terminal inside the folder that contains `package.json`.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite address shown in the terminal.

## Changes in this version

- Removed **Request Queue** from the admin sidebar.
- User **Services** now displays the Barangay Services cards shown in the provided screenshot.
- Clicking **Request a Service** from Overview switches the dashboard content to Services without changing the URL.
- Service selection, service form, and review are now handled as steps inside the same dashboard content area.
- Submitting a request switches to **My Requests** without navigating to another page.
